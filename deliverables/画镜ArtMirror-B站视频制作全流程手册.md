# 画镜 ArtMirror｜B站视频制作全流程操作手册

## 1. 目标与推荐成片规格

- 目标时长：3–5 分钟，推荐 4 分钟左右。
- 画面：1920×1080、16:9、30fps；录屏尽量保持 100% 缩放，避免字体发虚。
- 音频：48kHz，旁白峰值约 -6 dB，背景音乐比旁白低 18–24 dB。
- 导出：MP4 / H.264，1080p，码率 8–16 Mbps；音频 AAC 320 kbps 或编辑器高质量默认值。
- 视频风格：以真实操作为主，少量字幕和局部放大，不要让大量文字盖住图片主体。

## 2. 录制前准备

### 软件

- 录屏：OBS Studio（免费）或系统自带录屏工具。
- 剪辑：剪映专业版、DaVinci Resolve、Premiere 任一即可。
- 配音：优先真人旁白；也可使用剪映/系统 TTS，先确认商用和平台授权条款。
- 图片与素材：准备一组带工作流元数据的 ComfyUI PNG，另准备少量没有完整提示词的图片用于演示 AI 反推。

### 项目状态

1. 在项目根目录双击 `启动Web端-Win.bat`。
2. 等待浏览器打开图库页面，确认页面能显示图片。
3. 如果是第一次启动，允许依赖安装完成；不要在正式录制中展示长时间安装。
4. 提前在设置页添加测试图片目录并点击扫描。
5. 若要演示 AI，提前配置文本/视觉模型，点击“测试连接”，确认成功。
6. 清理不想出镜的文件名、API Key、电脑用户名、桌面私人文件和通知弹窗。

### 演示数据

- 优先使用自己生成或明确有授权的图片。
- 不要把真实 API Key 录进视频；设置页演示时用遮挡、空配置截图或提前录好的成功状态。
- 用一张测试图片演示删除，避免误删重要资产。
- 预先记录“原生提示词、反推结果、翻译结果、AI 评分”是否已存在，避免现场等待或按钮无结果。

## 3. OBS 录屏设置

1. 新建场景：`ArtMirror-主界面`、`ArtMirror-设置页`、`ArtMirror-详情页`。
2. 添加窗口捕获或浏览器窗口捕获；只捕获浏览器，不要录整个桌面。
3. 分辨率设置为 1920×1080，帧率 30fps。
4. 光标显示开启；鼠标移动慢一点，点击前停留约 0.5 秒。
5. 录一条系统声音测试和一条麦克风测试，确认没有回声、爆音、风噪。
6. 每个镜头开录前留 2 秒，操作完成后再留 2 秒，后期更容易剪切。
7. 录制顺序建议：主页浏览 → 详情页 → 设置页 → AI 功能 → 启动脚本补录。这样即使某个 AI 请求失败，也不影响主体素材。

## 4. 推荐录屏操作脚本

### A. 开场与主页

- 进入图库主页，先停在完整页面 2 秒。
- 鼠标依次指向导入、目录、三种视图、排序、搜索框。
- 录“已显示 X / 共 Y 张”统计信息，作为大图库能力的视觉证据。

### B. 三种视图与检索

- 点击平铺，停留一张卡片让观众读到尺寸、文件大小、模型和标签。
- 点击沉浸，滚动一屏，展示纯图片浏览。
- 点击聚合，展开一组，点击组标题提示词复制。
- 回到平铺，依次录目录筛选、排序、搜索一个关键词、点击一个标签。
- 不要快速连续点击；每个功能保留 2–4 秒结果状态。

### C. 详情与工作流

- 点击图片进入详情。
- 先展示大图，再展示提示词三源。
- 滚动到模型、LoRA、VAE 和采样参数。
- 打开工作流 JSON 预览，停留到关键字段可读；不要把整个 JSON 从头滚到底。
- 如需展示下载/复制/导出，录按钮点击后的结果，不要真的覆盖或删除文件。

### D. AI 与批量任务

- AI 反推、翻译、评分最好使用提前完成的结果或后期加速等待过程。
- 批量 AI 先展示选择“全部/按目录”、待处理数量和二次确认，再展示进度条；真实任务数量不宜太大。
- 失败项可作为“逐张隔离异常”的补充，但不要让失败成为主叙事。

### E. 设置页

- 展示添加图片目录、立即扫描、已扫描文件夹隐藏/恢复。
- 展示导入保存目录，强调拖拽图片会落到该目录并自动入库。
- 展示文本/视觉/Embedding 角色和“测试连接”。API Key 区域必须打码或不输入。
- 展示主题切换；主题变化后停留一秒，让观众看出即时生效。

## 5. 讲解与配音

### 真人配音方法

- 按脚本分段录，不要一次录完整 4 分钟。
- 语速约每分钟 220–280 字；技术名词之间留短停顿。
- 句子短一些，重点词稍微重读：`本地`、`工作流`、`三种视图`、`AI 反推`、`可复现`。
- 录音距离麦克风 10–15 cm，略偏离正前方，减少喷麦。
- 每段至少录两遍：一遍自然版，一遍更慢、更清晰版。

### AI 配音方法

- 把脚本按时间段拆成短句，避免长段落导致错音或节奏僵硬。
- “ArtMirror”可读作“画镜 ArtMirror”；“LoRA”读作“LoRA”；`workflow JSON`可读作“工作流 JSON”。
- 专有名词、英文厂商名和数字要人工试听。
- 不要用未经授权的名人声音或模仿特定创作者声音。

### 配音与画面对齐

- 先锁定旁白，再按旁白剪画面，效率高于先剪满屏操作。
- 旁白说“点击聚合”时，画面应在点击前后 1 秒内完成。
- 等待接口响应可加速到 2–4 倍，或用旁白覆盖；不要让观众长时间看加载。

## 6. 剪辑结构与字幕

### 时间线建议

- 0:00–0:20：痛点 + Logo/主页。
- 0:20–0:45：启动方式。
- 0:45–1:35：浏览与检索。
- 1:35–2:25：详情与工作流。
- 2:25–3:20：AI 增强。
- 3:20–3:50：设置维护。
- 3:50–4:10：总结、项目地址、关注提示。

### 字幕规则

- 一行尽量不超过 18–22 个汉字；两行以内。
- 功能名使用统一写法：`平铺 / 沉浸 / 聚合`、`原生 / 反推 / AI`。
- 关键按钮可做局部放大或加细描边，但不要用大面积弹窗遮盖图片。
- 图片上方不叠加角标或大段文字；提示信息放在图片旁边、下方或画面边缘。
- 字幕与鼠标不要同时遮住模型、提示词和图片主体。

### 转场与音乐

- 主体采用硬切或 6–10 帧淡入淡出，避免花哨转场抢走界面注意力。
- 背景音乐选择低存在感、可商用或明确授权的电子/Lo-fi 音乐。
- 开场和结尾音乐可略高，中段旁白时自动压低。
- 点击按钮可加轻微 UI 音效，但不要每次滚动都加音效。

## 7. B 站发布流程

1. 导出 1080p 成片，完整看一遍，检查画面和旁白是否错位。
2. 封面建议：画镜图库截图 + 大标题“ComfyUI 图片终于能找回工作流了” + 小字“ArtMirror 全功能介绍”。
3. 标题备选：
   - `ComfyUI 图片管理神器：画镜 ArtMirror 全功能介绍，提示词和工作流一键找回`
   - `生成图片太多找不到？用画镜 ArtMirror 管理 ComfyUI 图片、提示词和工作流`
4. 简介模板：

   > 画镜 ArtMirror 是一个用于管理本地 ComfyUI 产出图片的图库插件/本地 Web 工具。本期介绍图片导入、三种视图、搜索筛选、PNG 工作流解析、提示词管理、AI 反推/翻译/评分、批量 AI 和设置方法。\n\n> 项目地址：填写你的 GitHub 地址\n> 使用说明：填写 README 或文档地址\n> 说明：AI 功能需要配置对应的 OpenAI 兼容模型接口。

5. 标签建议：`ComfyUI`、`AI绘画`、`Stable Diffusion`、`工作流`、`提示词`、`图片管理`、`开源项目`。
6. 发布前选择合适分区，检查封面、标题、简介、字幕、项目链接和置顶评论。
7. 置顶评论可写：`你最希望图库增加哪一个功能？欢迎在评论区告诉我。`

## 8. 注意事项与常见问题

- Web 端启动脚本是本地服务，不代表已经部署到公网；视频里不要说“在线云图库”。
- 图片目录使用本地绝对路径；换电脑或移动目录后，需要在设置页重新配置。
- PNG 工作流解析依赖图片内嵌的 ComfyUI workflow/prompt 元数据；没有元数据时，详情里的工作流或原生提示词可能为空。
- AI 反推和 AI 评分需要视觉模型；翻译、标签解析、工作流解析需要文本模型；Embedding 配置按当前版本设置用途准备。
- AI 请求可能受网络、模型额度、接口格式和超时影响；视频中应使用“支持/可以配置”，不要承诺每个厂商都无条件可用。
- 删除演示必须使用测试文件。项目会将原文件移入系统废纸篓并软删记录，仍应在录制前备份重要目录。
- 不要在录屏中暴露 API Key、真实文件路径中的私人信息、聊天通知、浏览器书签或其他项目资料。
- B 站发布前确认背景音乐、图片、字体、配音和封面素材的使用授权。
