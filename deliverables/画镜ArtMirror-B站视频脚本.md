# 画镜 ArtMirror｜B站 3–5 分钟全功能介绍视频脚本

> 定位：面向使用 ComfyUI、经常生成大量图片、需要找回提示词/工作流的创作者。
> 建议成片：约 4 分钟；画面比例 16:9，录屏主体为 Web 端，最后补一句可嵌入 ComfyUI 侧边栏。
> 录制前准备：先双击 `启动Web端-Win.bat`，等待浏览器打开 `http://127.0.0.1:8000/gallery.html`；准备一组带 ComfyUI PNG 元数据的图片、一个可用的 OpenAI 兼容大模型配置。

## 二、逐段脚本（旁白 + 画面 + 字幕）

### 0:00–0:20｜开场：ComfyUI 图片终于不再“生成完就找不到”

**画面**：先用 2–3 秒图片墙/生成结果快速切换，再切到画镜图库主页；鼠标从图片卡片扫过。

**旁白**：

> 用 ComfyUI 生成图片，最容易遇到的不是不会生成，而是生成多了以后：图片散落在不同目录，提示词找不到，模型和参数记不住，想复现某张图还要重新翻工作流。今天介绍的画镜 ArtMirror，就是一个专门管理 ComfyUI 产出图片的本地图像资产工具。它能把图片、提示词、模型、采样参数和工作流放在同一个图库里，还能用 AI 帮你反推、翻译、打标签和评分。

**屏幕字幕**：`图片资产管理｜工作流解析｜AI 增强`

### 0:20–0:45｜启动：双击脚本，自动打开 Web 端

**画面**：桌面双击 `启动Web端-Win.bat`；展示命令窗口短暂检查 Python/依赖；浏览器打开画镜。不要长时间等待安装过程，可用加速剪辑。

**旁白**：

> Windows 用户直接双击“启动Web端-Win.bat”。脚本会检查 Python 环境，创建或复用虚拟环境，安装依赖，启动本地服务，并在健康检查通过后打开浏览器。首次启动可能需要联网安装依赖，之后就是等待服务启动即可。画镜是本地工具，图片数据库和缩略图都保存在本机，不需要把图片上传到云端才能浏览。

**屏幕字幕**：`首次启动需等待依赖安装；服务地址：127.0.0.1:8000`

### 0:45–1:35｜浏览与检索：三种视图，把图库变成可用的资产库

**画面操作顺序**：

1. 展示平铺视图：卡片包含缩略图、尺寸、文件大小、模型、提示词源和标签。
2. 点击“沉浸”：只看图片墙，展示适合挑选视觉方案。
3. 点击“聚合”：展示相同或相似提示词的分组；展开一组。
4. 切换目录下拉框、排序按钮；在搜索框输入模型名或关键词。
5. 点击一个标签 chip，展示标签筛选；滚动触发加载更多。

**旁白**：

> 进入图库后，平铺视图适合管理：每张卡片同时显示图片尺寸、文件大小、模型、提示词来源和属性标签。想专心看图，可以切换到沉浸视图，把界面变成一面图片墙。聚合视图则会按相同或相似提示词分组，适合快速找到同一套提示词生成的系列图。
>
> 检索也很直接：可以按目录筛选，按时间、AI 评分或人工评分排序；搜索会匹配文件名、正向提示词、负向提示词和标签，结果会优先展示标签命中的图片。图库采用分页和滚动加载，大量图片也不需要一次性把全部内容塞进页面。

**屏幕字幕**：`平铺：管理｜沉浸：浏览｜聚合：复用提示词`

### 1:35–2:25｜图片详情：从一张图找回完整生成上下文

**画面操作顺序**：点击一张图片进入详情；展示大图；点击提示词源“原生/反推/AI”；展示模型和参数；打开工作流 JSON 预览，再展示导出/复制入口；可双击大图展示缩放平移。

**旁白**：

> 点击图片进入详情页。这里不只是放大图片，而是把生成上下文一起找回来。左侧是原图预览，双击还能进入拖拽平移和滚轮缩放的大图模式；右侧可以查看提示词、模型资源和采样参数。
>
> 提示词支持原生、AI 反推和 AI 解析三种来源，正向与负向内容可以分段查看和复制。模型信息会解析主模型、LoRA 和 VAE；采样参数包括 steps、CFG、sampler、scheduler、seed 以及分辨率。更重要的是，PNG 中有 ComfyUI 工作流元数据时，可以预览或导出 workflow JSON，之后拖回 ComfyUI 继续复现和修改。

**屏幕字幕**：`图片不是孤立文件，而是一条可复用的生成记录`

### 2:25–3:20｜AI 增强：让旧图片重新变得可理解、可复用

**画面操作顺序**：在设置页先快速展示模型配置位置；回到详情页点击“反推提示词”，等待结果；切换翻译；展示 AI 评分明细；回设置页展示批量 AI 按全部/按目录执行和进度弹窗。若没有 API Key，用提前准备好的结果演示，避免现场等待。

**旁白**：

> 配置好文本模型和视觉模型后，画镜可以进一步处理图片。第一项是视觉模型反推提示词：即使原图没有完整提示词，也可以从画面生成一份可继续使用的描述。第二项是 AI 属性标签，它会从提示词中提取画面、风格和内容标签，方便之后筛选。
>
> 提示词还支持中英互译，翻译结果会保存下来，下一次切换语言不需要重复请求。AI 评分会从多个维度评价画面，并给出分数和理由；人工评分也支持一到五星，可以混合使用。
>
> 如果图片很多，设置页还提供批量 AI：可以选择全部图片或某个目录，执行反推、标签解析、翻译或评分。开始前会显示待处理数量，执行中有进度、成功数和失败数，也可以随时终止；已经处理过的图片会自动排除，避免重复消耗额度。

**屏幕字幕**：`反推｜标签｜翻译｜AI 评分｜批量任务`

### 3:20–3:50｜设置与维护：一次配置，长期自动同步

**画面操作顺序**：打开设置页；展示添加扫描目录、立即扫描、已扫描文件夹隐藏/恢复；展示导入保存目录；展示模型角色与测试连接；展示主题卡片和 PNG/JPG 压缩设置（如当前版本界面有显示）。

**旁白**：

> 设置页主要有四块。第一是图片目录：可以添加多个本地绝对路径，立即重新扫描，也可以隐藏某个已扫描文件夹，让它暂时不出现在图库里。第二是导入配置：浏览器导入或拖拽的图片会保存到指定目录，并自动加入扫描范围。
>
> 第三是大模型配置，文本、视觉和 Embedding 角色可以分别配置，也支持 DeepSeek、通义千问、智谱、OpenAI 或自定义的 OpenAI 兼容接口；保存后建议点击“测试连接”。最后是主题和 AI 提示词自定义。后台会定期增量扫描，图库通过同步版本变化刷新，所以 ComfyUI 新生成的图片可以自动进入图库。

### 3:50–4:10｜结尾：把生成结果变成自己的资产库

**画面**：快速回放三种视图、详情工作流、AI 评分；最后停在主页 Logo/图库。

**旁白**：

> 总结一下，画镜 ArtMirror 解决的是 ComfyUI 产出之后的管理问题：用图库找图，用标签和搜索定位，用 PNG 元数据找回提示词和工作流，再用 AI 把没有整理过的图片补齐描述、翻译和评分。它适合本地单机使用，数据不拷贝原图，只保存图片引用和分析结果。
>
> 如果你也在用 ComfyUI，欢迎把画镜加入自己的工作流。视频下方我会放项目地址和使用说明；如果这期介绍对你有帮助，欢迎点赞、收藏和关注。

## 四、发布前事实核对

- “本地保存”应表述为：原图不写入数据库，图库保存本地路径引用、SHA-256 与 meta；缩略图单独缓存。
- AI 功能依赖用户配置可用的模型接口，不要承诺“无需 API Key”。
- 删除操作会把原文件移入系统废纸篓并软删记录，演示删除前应使用测试图片并明确提示。
- 录制时可用 Web 端；实际作为 ComfyUI 插件使用时，图库会出现在侧边栏，底层功能一致。
