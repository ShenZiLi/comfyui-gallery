# 画镜 ArtMirror — 功能清单

> 本清单记录项目全部功能点，供开发与设计对照参考。
> **维护规则**：每新增一个功能点，必须在本文件补充对应条目，并同步更新「更新记录」。
> 分类原则：**优先按页面归类，其次按功能类型归类**。

***

## 图库页（gallery.html）

### 图片导入

* [x] 浏览器导入：点击「导入」选择本地图片（支持多选）上传

* [x] 外部拖拽导入：将图片文件拖入图库页面即上传

* [x] 导入后自动扫描入库：上传到「导入保存目录」后触发后台扫描并实时刷新

### 浏览与检索

* [x] 图片浏览：平铺 / 沉浸两种视图

* [x] 目录筛选：按下拉选择特定目录查看

* [x] 排序：按时间 / AI 评分 / 人工评分

* [x] 关键词搜索：匹配提示词、负向提示词、文件名（结果高亮）

* [x] 标签筛选：按模型 / LoRA / VAE / 风格等标签 chips 筛选

* [x] 大库分页加载：列表接口分页（60 张/页）+ 无限滚动（IntersectionObserver 预加载 600px）

* [x] 大库性能：卡片数据批量组装（消除 N+1 查询）、卡片瘦身（详情字段仅详情页返回）、查询索引

* [x] 后台更新提示条：扫描同步不再自动重拉列表，顶部提示「后台有更新 · 点击查看」

* [x] 详情页返回：无限滚动下自动补页恢复滚动位置（上限 50 页）

### 卡片与操作

* [x] 卡片信息：尺寸、文件大小、AI 评分

* [x] 卡片操作：复制图片、下载原图、删除（二次确认）

* [x] 物理删除 + 回收站：删除时原文件移入系统废纸篓（可恢复）

* [x] 模型展示：主模型 + LoRA 标签 chips

* [x] AI 解析：用大模型解析模型标签与 AI 提示词

* [x] 提示词三源切换：原生 / 反推 / AI

* [x] 提示词复制、工作流 JSON 预览

* [x] 平铺提示词行分级压缩：列数 ≤4 隐藏「提示词」字样；≤3 来源标签与操作图标分两行；≤2 来源标签纯图标化（彩色圆点）

### 聚合

* [x] 按提示词聚合：相同 / 相似提示词分组（相似聚类阈值为 0.92）

* [x] 组内成员展开查看、封面与最高 AI 评分展示

* [x] 聚合分页与懒加载：组列表分页（20 组/页）、封面行 ≤6 张、组内成员展开懒加载（24 张/页）

* [x] 聚合预览提示词单击复制：单击组标题提示词直接复制到剪贴板并提示（hover 高亮 + 手型光标）

* [x] 聚合受目录选择控制：按提示词聚合与组内成员仅显示当前所选目录下的图片（含隐藏目录过滤）

## 设置页（settings.html）

### 图片目录管理

* [x] 添加图片目录：输入本地路径入库（链接式，非拷贝）

* [x] 移除图片目录：解除图片链接并清理目录节点

* [x] 导入保存目录：输入本地文件夹绝对路径，作为图库导入/拖拽图片的保存位置；未配置时回退到应用数据目录下的自管导入区

* [x] 三角色独立配置：文本 / 视觉 / Embedding，支持不同厂商混搭

* [x] 测试连接：一键并发验证文本 / 视觉 / Embedding 三模型连通性，分别显示成功/失败

* [x] AI 提示词配置：反推/评分/互译/工作流解析四功能提示词可自定义，留空用内置默认

## 公共 / 系统能力

### 展示与体验

* [x] 明暗主题切换，刷新保持

* [x] 全局导航栏注入

* [x] 品牌图标：抠图后多尺寸输出（16/32/48/64/96/128/192/256/512 + favicon.ico 多档 + apple-touch-icon 180），替换原 SVG 渐变 logo，浏览器标签栏 / PWA 主题色统一

### 实时同步

* [x] 后台增量扫描：每 20s 扫描注册根目录

* [x] 前端轮询：每 3s 轮询 `/api/sync/version`，版本变化即刷新图库

* [x] 本地图片增删实时反映到图库

### 数据与存储

* [x] SQLite 数据库：只存图片引用与 meta，不存图片字节

* [x] SHA-256 去重，缩略图以 `<sha>.webp` 缓存

* [x] 软删除（`is_deleted=1`）

### ComfyUI 解析

* [x] PNG 内嵌 workflow / prompt 图解析

* [x] 解析模型、LoRA、VAE、参数与多段提示词

### 前端架构

* [x] 离线回退：后端不可用时自动切换 mock 数据

* [x] 静态资源 no-cache，前端改动刷新即生效

* [x] 依赖本地化：Alpine.js 内置到 `frontend/vendor/`，不依赖外网 CDN

### 部署 / 启动

* [x] Windows 一键启动：双击 `启动.bat` → 检测 Python(≥3.11) → 创建/复用 `.venv` → pip 安装 `requirements.txt` 依赖 → 后台启动 uvicorn → 轮询健康检查后自动打开浏览器；端口已被占用时视为服务已在运行直接开浏览器；回车停止并清理后台进程，日志落盘 `data/server.log` / `server.err.log`

* [x] ComfyUI 插件集成：`comfyui-plugin/` 打包为自定义节点（侧边栏内嵌「图库」tab、/artmirror/\* 反向代理到进程内 FastAPI、默认扫描 ComfyUI 输出目录、可发布 Comfy Registry）

* [x] Web 端与插件统一底层代码（纯生成物）：`backend/app`、`frontend/` 为唯一真源；插件内 `artmirror_app/`、`static/` 为同步脚本生成的副本（不提交 git、勿手改），`sync_all.py` 一键同步，`--check` 逐文件校验副本与真源一致（漂移退出码非 0）
