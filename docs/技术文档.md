## 一、项目定位与仓库

ArtMirror 画镜 = ComfyUI 图片/提示词资产管理工具：浏览、管理、检索本地 ComfyUI 产出图片，
解析内嵌 workflow meta，并提供 AI 增强（反推提示词、中英翻译、AI 评分）。

- **仓库根即插件**：`__init__.py` + `web/` + `requirements.txt` + `artmirror/`，
  可直接作为 ComfyUI 插件（解压到 `custom_nodes/ArtMirror` 即用）。
- **仓库地址**：`git@github.com:ShenZiLi/comfyui-gallery.git`（remote `origin`），
  另设镜像插件仓库 `gallery`（`git@github.com:ShenZiLi/comfyui-gallery.git` 的 ComfyUI 安装副本）。
- 后端 FastAPI + SQLModel(SQLite) + Pillow + httpx；前端零构建静态页（Alpine.js + 手写 CSS）。

## 二、本地启动 / 部署

依赖用 `uv` 管理，无需手工建 venv。

```bash
cd C:\Project\Code\comfyui-gallery
uv sync                                   # 安装/同步依赖（首次）
uv run uvicorn launchers.web.main:app --host 127.0.0.1 --port 8000
```

- 前端无需独立服务；浏览器访问：
  - `http://127.0.0.1:8000/gallery.html` 图库
  - `http://127.0.0.1:8000/settings.html` 设置
  - `http://127.0.0.1:8000/docs` 后端 OpenAPI
- 健康检查：`curl http://127.0.0.1:8000/api/health`
- 也可用根目录脚本 `启动Web端-Win.bat`（Windows）/ `启动Web端-Mac.command`（macOS）一键启动。

### 数据与目录

- 运行数据在 `data/`（`data/artmirror.db` + `data/thumbs/`），已被 `.gitignore` 忽略。
  - 清空数据 = 删 `data/artmirror.db` 与 `data/thumbs/`（图片目录不受影响）。
- 扫描目录通过设置页「图片目录」注册（校验 `Path.is_dir()`，审核路径防穿越）。
- 每图**只存引用**（`abs_path`/`sha256`）与 meta，不存图片字节；缩略图在 `data/thumbs/<sha>.webp`。
- 静态资源已启用 `Cache-Control: no-cache`，前端改动刷新即生效。

## 三、解析器能力（artmirror/parsers/comfyui_parser.py）

解析 ComfyUI 内嵌的 workflow/prompt 图，当前能力（与实际代码一致）：

| 能力 | 实现锚点（函数 / 常量） |
|---|---|
| UI 格式 / API 格式双解析 | `parse_prompt_graph` / `extract_prompt_lists(_ui)` / `parse_bytes` |
| 正向 / 负向提示词提取 | `_node_text` / `_ui_node_text` / `_looks_negative` |
| 主模型 / LoRA 提取 | `extract_assets` + `LORA_LOADERS` / `MAIN_MODEL_LOADERS` / `_trace_model` |
| seed / 采样参数 | `extract_sampler_params`（`_resolve_seed`：字面量 / `noise_seed` / 引脚回溯）|
| 文本联结 / 多段提示词 | `extract_prompt_lists`（`PASSTHROUGH_NODES` / API 与 UI 双格式）|
| 文本源节点白名单 | `TEXT_SOURCE_NODES`（含 `JjkText`）/ `UI_TEXT_NODES` / `POSITIVE_NODES` |
| 工作流回填 | `_apply_workflow_prompts` |

**已实现的解析器增强**：
- **`JjkText` 文本源**：krea2-muse 等用其承载正向提示词，加入 `TEXT_SOURCE_NODES` 与 `UI_TEXT_NODES`。
- **中文负面词过滤**：`_looks_negative` 补 `马赛克/低分辨率/模糊/水印/乱码` 等中文词 + `mosaic`/`censored`，
  避免中文负向提示词被误判为正向污染 `prompt`。
- **seed 解析增强**：`_resolve_seed` 支持字面量、`noise_seed`（`KSamplerAdvanced`）、
  seed 为引脚引用 `[node_id, 0]` 时回溯到 `Seed (rgthree)` 等源节点取字面值。
- **easy loraStack 提取**：`EASY_LORA_STACKS = {easy loraStack, easy loraStackApply}`，
  UI 格式 `widgets_values` 每 4 项一组、API 格式 `lora_i_name`/`lora_i_strength` 直列；
  以 `num_loras` 限制参与堆叠的**槽位数量**（超上限的历史残留槽位跳过）、`strength==0` 排除、
  负权重仍算在用。
- **CR Text Concatenate 文本联结**：`TEXT_MERGE_NODES`，把多个 `text*` 输入按 `separator` 拼成一条；
  节点/输入源 `mode==4`（bypass）跳过；已并入拼接的源文本不再作为独立提示词块收集（API/UI 双格式）。
- **LoRA 权重落库**：`extract_assets` 返回 `lora_weights=[(name, strength)]`，落
  `WorkflowMeta.loras_json` 新列（database `_migrate_sqlite`），详情页 chip 追加权重展示。

## 四、前端布局与主题（image.html / style.css）

### 4.1 详情页布局判定

- `image.html` `ratioClass()`：`(w/h) > 2.3 ? "landscape" : "portrait"`。
- 语义**与命名相反**（已知点，按用户设定保留）：
  - `landscape`（横图但极宽，>2.3）→ **单列上下堆叠** `grid-template-columns: 1fr`
  - `portrait`（其余）→ **左右分栏** `grid-template-columns: minmax(0,1.1fr) minmax(0,1fr)`
- `<900px` 窄屏统一 `1fr` 单列（移动端响应式）。

### 4.2 图片预览 / 放大

- **双击图片预览窗（`.pv`）**：深色舞台，滚轮缩放 1–8 倍、指针拖拽平移、
  双击/`Esc`/遮罩均可关闭。
  - 状态字段 `previewOpen / pvScale / pvX / pvY / pvDragging`；方法 `openPreview / closePreview / pvWheel`。
- **详情放大镜（`.magnifier` / `magnify`）**：`@mousemove="mag..."` 定位，原图放大查看。

### 4.3 主题系统（4 套）

| key | 风格 | 说明 |
|---|---|---|
| `light` | 亮色（默认） | 浅灰白底 + 蓝品牌色 |
| `dark` | 暗色 | 深蓝灰底 |
| `claude` | Claude 风格 | 暖米白 + 陶土橙，仿 Claude.ai（内联于 style.css）|
| `spacex` | SpaceX 暗黑 | 独立文件 `frontend/themes/spacex.css`，经 `themes.css` 引入 |

- 主题持久化：偏好写入后端 DB（`theme` 设置项）+ localStorage。
- 设置页「主题」板块卡片选择；导航栏右上按钮只做亮/暗快捷切换。
- 曾落地后删除的主题（Linear / Apple / Stripe）不在此列。

### 4.4 压缩（JPG 有损）

- 纯 Pillow 实现、零新增依赖（`artmirror/services/compress.py` 的 `to_jpg`）。
- 统一输出 `.jpg`；透明图片按白底合成（`_to_rgb_white`）。
- `compress_mode`：
  - `new`（默认）：写 `<stem>_compressed.jpg` 到导入保存目录并注册为扫描根重新入库；
  - `overwrite`：原图备份到废纸篓、原路径覆盖为有损 `.jpg`（见下「硬规则」）。
- `compress_quality` 60–95，默认 80。
- **压缩后若反而变大则跳过不写**（`_compress_one` 判断 `len(data) >= old`）。
- 支持单张（`POST /api/images/{id}/compress`）与批量
  （`POST /api/images/batch-compress`，裸数组 `ids`，逐张独立、异常隔离）。
- **视觉模型前置压缩**：反推/评分上传视觉模型前，一律先做一次 JPG 有损压缩
  （质量 80、最长边 1600）再 base64（`llm._encode_image`）。

### 4.5 属性标签

- 类别约定 **`attr`**（与 model/lora/vae/style/special 并存）。
- **gallery**：提示词行「AI」按钮 → 文本模型从提示词提取 ≤4 个属性标签打标
  （`POST /api/images/{id}/auto-tag`，追加合并），展示在提示词文本下方。
- **image 详情**：提示词下方属性标签区 —— 双击改名（删旧+加新）、右侧 × 删除、
  末尾 ＋ 手动新增；空名/纯空格拒绝。
- 接口：`POST /api/images/{id}/tags`（加）、`DELETE /api/images/{id}/tags`（删）。

## 五、硬规则

- **不改 ComfyUI 核心代码**，只改插件侧（`artmirror/` + `frontend/`）。
- `data/` 为运行数据，可删库重建；图片目录只被「链接引用」，不得被改写污染。
  - 扫描根**不应设为承载原始元数据的重要目录**；压缩 `overwrite` 会覆盖原路径，
    使用前确认该目录可被改写（覆盖前有废纸篓备份）。
- 每次功能点变更后，**同步更新 `docs/功能清单.md`**（AGENTS.md 规则）。
- 前端改动**不做自动化浏览器验证**，由用户强刷（`Cmd+Shift+R`）核对。
- 动效须统一使用 `--ease-*`/`--dur-*` 令牌，并纳入 `prefers-reduced-motion` 关闭机制。
- 图片上方不被图标/文字遮盖；提示信息放在图片之外。
