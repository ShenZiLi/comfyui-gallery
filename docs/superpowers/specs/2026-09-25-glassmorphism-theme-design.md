# 磨砂玻璃暗色主题设计

日期：2026-09-25
状态：待用户审阅

## 目标

为设置页增加一个独立可选的 Glassmorphism 暗色主题，采用用户在视觉预览中选择的 A「极光靛蓝」方向。复用现有主题设置和持久化机制；现有主题保持原样。

## 视觉规则

- 画布使用深蓝灰色，并以低饱和靛蓝、紫色柔光营造层次，不使用全屏动画。
- 导航、常规 UI 面板、下拉、输入控件、弹窗使用半透明暗色层、约 15px 背景模糊、细微白色描边及轻量内侧高光。
- 保留清晰的文本层级与可见键盘焦点；控件文字满足足够对比度。
- 图片像素保持原样，图片上方不叠加主题装饰、图标或文字。
- 若浏览器不支持 `backdrop-filter`，面板回退到足够不透明的深色背景，保证信息可读。

## 结构与数据流

- 在设置页主题列表新增 `glass` 键、中文名称、说明与独立预览色块。
- 在 `frontend/themes.css` 引入 `frontend/themes/glass.css`。
- 新 CSS 只使用 `html[data-theme="glass"]` 作用域及主题专属变量，不修改共享基础选择器或现有主题规则。
- 继续使用现有 `App.currentTheme()`、设置页 `pickTheme()` 和 `/api/settings` 持久化路径，不新增后端字段或迁移。
- 通过现有提前读取 `localStorage` 的逻辑实现刷新后首绘主题恢复。

## 文档

在 `docs/功能清单.md` 的「外观主题」中增加 Glassmorphism 条目，并在更新记录添加一行，描述主题方向和 CSS 隔离范围。

## 验收标准

1. 设置页出现可选的「磨砂玻璃」主题卡片，点击即时应用并按现有机制持久化。
2. `glass` 样式应用于全站公共界面层，包含图库导航、设置面板、下拉、输入控件和弹窗。
3. 玻璃层具有可见的透明度、背景模糊、浅色细边及靛蓝环境光；文字、输入值和键盘焦点清晰可辨。
4. 图片展示区域不被主题元素遮挡或更改。
5. 其他主题的 CSS 及主题卡片选择行为无变化。
6. 按仓库约定重启本地服务并确认 `/api/health` 可访问；前端主题不进行自动化浏览器验证。

## 范围外

- 不调整其他主题、主题快捷切换按钮或主题持久化后端逻辑。
- 不新增依赖、图片素材或构建步骤。
